# IFNRCON 2026 — Face Search System

AI-powered face recognition system built for IFNRCON 2026 medical conference.

## 🚀 Features
- Face recognition using AWS Rekognition
- Login with Registration ID + Email
- Search across 4000+ event photos
- Admin panel for indexing
- Download matched photos

## 🛠️ Tech Stack
- **Backend:** ASP.NET Core 9 MVC
- **Database:** MySQL
- **AI/ML:** AWS Rekognition
- **Storage:** AWS S3
- **Frontend:** HTML, CSS, JavaScript

## 📸 How It Works
1. Attendee logs in with Registration ID + Email
2. Uploads their face photo
3. AWS Rekognition searches through all event photos
4. Matched photos are displayed instantly

## ⚙️ Setup

### Requirements
- .NET 9 SDK
- MySQL Database
- AWS Account (Rekognition + S3)
- Visual Studio 2022
